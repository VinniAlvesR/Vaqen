# Vaqen — Documentação Oficial (V4)

## Status do Projeto
Versão Atual: V4
Status: Em desenvolvimento ativo

## 1. Visão do Produto
Vaqen é uma plataforma web de gestão para freelancers, desenvolvedores, designers e pequenas equipes.

## 2. Objetivo
Permitir que profissionais acompanhem todo o fluxo de trabalho sem depender de múltiplas ferramentas.

Princípios:
- Simplicidade
- Produtividade
- Organização
- Velocidade

## 3. Público-Alvo
- Freelancers
- Desenvolvedores
- Designers
- Pequenas agências
- Empreendedores digitais

## 4. Histórico de Versões
### V1 — MVP
CRUDs, SQLite e API Routes.

### V2 — UX & Organização
Melhorias visuais, feedbacks e refatoração.

### V3 — Identity & Security
Cadastro, login, logout, sessões, middleware e proteção de rotas.

## 5. Arquitetura Tecnológica
